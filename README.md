# VerifyKaro

### Check before you trust.

VerifyKaro is an AI-powered verification tool designed to help users evaluate suspicious messages, emails, job offers, links, payment requests, screenshots, and other potentially risky content.

Instead of simply returning "safe" or "scam", VerifyKaro analyzes available signals, performs supporting verification checks, calculates a risk score, and explains why the content may be suspicious.

---

## Features

- Analyze suspicious messages and text
- Verify suspicious links and URLs
- Analyze job offers and recruitment messages
- Detect payment requests and scam indicators
- Upload screenshots and PDFs for analysis
- Extract readable content from uploaded files
- AI-powered contextual analysis
- External verification checks where available
- Deterministic risk scoring
- Low / Medium / High risk classification
- Evidence-based explanations
- Actionable recommendations
- Rate limiting for verification requests
- Responsive web interface
